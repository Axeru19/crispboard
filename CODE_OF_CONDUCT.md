# Code of Conduct

We want Crispboard to be a welcoming project for everyone.

## Our standard

- Be respectful and constructive. Disagree with ideas, not with people.
- Assume good faith and help newcomers.
- No harassment, discrimination, personal attacks or publishing other people's private information.
- Keep discussions on topic: the project, its code and its users.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat offenders.

To report a problem, use GitHub's *Report content* feature or contact the maintainer through the email on their GitHub profile.

This code is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
